## อัปเดต / Updates

ตั้งค่า repository เป็น `kue-kid/Subtitle-Flow-Auto-Releases` โดยไม่ต้องกรอก Token

ผู้ใช้ 1.6.0 เปลี่ยนช่อง repository ครั้งเดียวแล้วกดบันทึกและตรวจอัปเดต หรือดาวน์โหลด Portable ชุดใหม่ รุ่น 1.6.1 เป็นต้นไปใช้ปลายทางนี้เป็นค่าเริ่มต้น

ใช้ไฟล์ `.sha256` ที่ชื่อคู่กันเพื่อตรวจความสมบูรณ์ของ ZIP ชุดฟรีอาจมีคำเตือนผู้พัฒนาจากระบบปฏิบัติการเมื่อเปิดครั้งแรก

รีโปนี้เก็บเฉพาะข้อมูลดาวน์โหลดและไฟล์แจก ซอร์สหลักยังพัฒนาในรีโป Private แยกต่างหาก
